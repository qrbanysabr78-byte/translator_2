# مترجم هوشمند زبان اشاره — Hugging Face Space

این نسخه برای **Docker Space** آماده شده است. آموزش مدل در زمان بالا آمدن Space اجرا نمی‌شود؛ فایل مدل و کلاس‌ها باید یک‌بار ساخته و سپس در مخزن Space قرار داده شوند.

## فایل‌هایی که باید در ریشه Space باشند

- `Dockerfile`
- `requirements.txt`
- `app.py`
- `train_once.py` (فقط برای آماده‌سازی مدل؛ لازم نیست Space آن را اجرا کند)
- `templates/index.html`
- `gru_original_fine_tuned.keras` (پس از آموزش یک‌باره)
- `class_names.npy` (پس از آموزش یک‌باره)
- `SSL400_Data/` (اگر قابلیت جست‌وجو و پخش ویدیوهای نمونه باید فعال باشد)

## آماده‌سازی مدل فقط یک بار

در محیطی با فضای دیسک و RAM کافی (ترجیحاً Colab یا کامپیوتر دارای منابع مناسب):

1. وابستگی‌های آموزش را نصب کنید: `pip install -r requirements.txt kaggle tqdm scikit-learn`
2. توکن Kaggle را در متغیر محیطی `KAGGLE_API_TOKEN` قرار دهید؛ توکن را داخل فایل کد ننویسید.
3. `python train_once.py` را اجرا کنید. این اسکریپت دیتاست را می‌گیرد، ویژگی‌های ۳۰ فریم/۱۲۶ عددی را استخراج می‌کند و معماری GRU تعریف‌شده در نوت‌بوک را آموزش می‌دهد.
4. فایل‌های `gru_original_fine_tuned.keras` و `class_names.npy` را کنار `app.py` قرار دهید.
5. پوشه `SSL400_Data/` را هم بارگذاری کنید تا ویدیوهای نمونه در سایت در دسترس باشند. اگر بارگذاری کل دیتاست بیش از حد بزرگ است، می‌توان ویدیوهای موردنیاز را در یک مخزن Dataset جداگانه نگهداری کرد و مسیر دانلود را بعداً تنظیم کرد.

## ساخت Space

1. در Hugging Face گزینه **New Space** را بزنید.
2. SDK را روی **Docker** و Visibility را روی **Public** بگذارید.
3. فایل‌های بالا را در مخزن Space بارگذاری کنید.
4. در Settings → Variables and secrets یک Secret با نام `GEMINI_API_KEY` اضافه کنید. این کلید نباید داخل فایل‌های عمومی قرار بگیرد.
5. پس از Build موفق، برنامه روی پورت `7860` اجرا می‌شود.

## نکته مهم درباره دوربین

مرورگر برای دسترسی به دوربین به HTTPS و اجازه کاربر نیاز دارد. لینک عمومی Hugging Face معمولاً HTTPS است؛ بازدیدکننده باید دسترسی دوربین را تأیید کند.

## نکته درباره ویدیوها و محدودیت منابع

مدل و ویدیوهای دیتاست می‌توانند حجم زیادی داشته باشند. برای فایل‌های بزرگ از Git LFS یا مخزن Dataset استفاده کنید. Space رایگان ممکن است برای بارگذاری همه ویدیوها یا اجرای TensorFlow/MediaPipe محدودیت RAM و فضای ذخیره‌سازی داشته باشد. اجرای عمومی به معنی روشن ماندن دائمی Space نیست؛ در حالت بی‌استفاده ممکن است به خواب برود.

## بررسی سلامت

پس از اجرا، مسیر `/health` وضعیت بارگذاری مدل و تعداد ویدیوهای ایندکس‌شده را نشان می‌دهد.
